Citation Analysis Setup

Install Docker and run GROBID

GROBID is required for citation-link suggestions. Research Mind Map can run without it, but the GROBID citation-analysis workflow needs this local service.

What GROBID Does

GROBID reads scholarly PDFs and extracts structured reference information. In this app, it helps identify citation relationships between publications that are already on your map.

You can use the basic mind map, OpenAlex discovery, Zotero imports, notes, PDFs, and autosaves without GROBID. For citation-link suggestions from local PDFs, Docker and GROBID are required.

Install Docker

Docker runs GROBID in a container, which avoids installing GROBID directly into your Python environment.

  • Windows: install Docker Desktop. You can run the commands below in Windows PowerShell, Command Prompt, or the VS Code integrated terminal.
  • macOS: install Docker Desktop. You can run the commands below in the macOS Terminal app or the VS Code integrated terminal.
  • Ubuntu: install Docker Engine or Docker Desktop. You can run the commands below in Ubuntu Terminal or the VS Code integrated terminal.

After installation, open the terminal for your operating system and check Docker.

Windows PowerShell:

docker --version

Windows Command Prompt:

docker --version

macOS Terminal:

docker --version

Ubuntu Terminal:

docker --version

If Docker is installed and running, this should print a Docker version number.

Start Docker

On Windows and macOS, open Docker Desktop and wait until it says Docker is running. On Ubuntu, start Docker Desktop or make sure the Docker Engine service is running.

Check that Docker can list containers.

Windows PowerShell:

docker ps

Windows Command Prompt:

docker ps

macOS Terminal:

docker ps

Ubuntu Terminal:

docker ps

If Docker is running, this prints a container list. The list can be empty.

Run GROBID

The commands are the same across operating systems. Choose the terminal that matches your setup.

You do not need to keep GROBID running all the time. Start it before citation analysis, and stop it when you are done.

Windows PowerShell

Pull the recommended GROBID image:

docker pull grobid/grobid:0.9.0-full

Create and start a reusable GROBID container:

docker run --name grobid -p 8070:8070 grobid/grobid:0.9.0-full

Windows Command Prompt

Run the same Docker commands:

docker pull grobid/grobid:0.9.0-full
docker run --name grobid -p 8070:8070 grobid/grobid:0.9.0-full

macOS Terminal

Run the same Docker commands:

docker pull grobid/grobid:0.9.0-full
docker run --name grobid -p 8070:8070 grobid/grobid:0.9.0-full

On Apple Silicon, the full image can be large and slower to start. If needed, grobid/grobid:0.9.0-crf is a smaller CPU-only alternative.

Ubuntu Terminal

Run the same Docker commands:

docker pull grobid/grobid:0.9.0-full
docker run --name grobid -p 8070:8070 grobid/grobid:0.9.0-full

With this foreground command, keep the terminal that is running GROBID open while using citation analysis. The first startup can take time because GROBID loads its models. Press Ctrl + C when you are done.

If you prefer to run GROBID without keeping a terminal occupied, use detached mode in Windows PowerShell, Windows Command Prompt, macOS Terminal, or Ubuntu Terminal:

docker run --name grobid -d -p 8070:8070 grobid/grobid:0.9.0-full

A reusable container named grobid will appear in Docker Desktop. After that, you can start, stop, restart, or pause it from Docker Desktop instead of typing the full docker run command again.

Expected service details:

Docker image: grobid/grobid:0.9.0-full
Container name: grobid
Service URL: http://127.0.0.1:8070
Health endpoint: GET /api/isalive
Reference endpoint: POST /api/processReferences

Manage GROBID in Docker Desktop

After the GROBID container has been created once, Docker Desktop can manage it from the Containers view.

  1. Open Docker Desktop.
  2. Go to Containers.
  3. Find the container named grobid.
  4. Use the controls to start, stop, restart, pause, or resume the container.

You do not need GROBID running in the background all day. Start it when you plan to use citation analysis in Research Mind Map, and stop or pause it when you are finished.

Opening Docker Desktop starts Docker itself, but it does not always start the GROBID container automatically. If grobid is stopped, start it from Docker Desktop before clicking Check GROBID in the app.

If you created the container with --rm, Docker removes it when it stops, so it will not appear later in Docker Desktop. The commands in this guide do not use --rm so the container can be reused.

Start and Stop GROBID from the App

Research Mind Map can also start and stop an established Docker GROBID container from the GROBID panel.

  1. Start Docker Desktop or Docker Engine first.
  2. Start the Research Mind Map backend with Uvicorn.
  3. Open the app in the browser.
  4. Open Sources, then GROBID.
  5. Click Check GROBID to refresh the current service state.
  6. If GROBID is stopped, click the green Start GROBID button.
  7. If GROBID is running, click the red Stop GROBID button when you are done.

While the app is checking, starting, or stopping GROBID, the button turns grey and is temporarily disabled. Analyze All Publications is enabled only when GROBID is running.

The app uses Docker on the computer running server.py. If Docker Desktop is closed, Docker is not accessible, or the backend process does not have Docker permission, the app cannot start or stop the container.

Check the Service

On Windows PowerShell, run:

Invoke-RestMethod -Uri "http://127.0.0.1:8070/api/isalive"

In Windows Command Prompt, run:

curl http://127.0.0.1:8070/api/isalive

In macOS Terminal, run:

curl http://127.0.0.1:8070/api/isalive

In Ubuntu Terminal, run:

curl http://127.0.0.1:8070/api/isalive

A healthy service should respond after GROBID finishes starting. If the first check fails, wait a minute and try again.

Use It in the App

  1. Start the Research Mind Map backend with Uvicorn.
  2. Start GROBID from the app's green Start GROBID button or from Docker Desktop.
  3. Import publication nodes from Zotero.
  4. Make sure those Zotero items have local PDF attachments.
  5. Open the GROBID tools in the app.
  6. Click Check GROBID.
  7. Analyze publications, review suggestions, and add only the citation links you want.

GROBID can only analyze PDFs that are available on the machine running the FastAPI backend. A remote browser user does not run GROBID on their own computer.

Stop GROBID

If GROBID is running in the foreground, go to the terminal where it is running and press Ctrl + C. This applies to Windows PowerShell, Windows Command Prompt, macOS Terminal, and Ubuntu Terminal.

If GROBID is running in detached mode, stop it from Docker Desktop or from any terminal with Docker access:

docker stop grobid

Troubleshooting

Docker command is not recognized

Docker is not installed, or your terminal was opened before Docker was installed. Install Docker Desktop or Docker Engine, then reopen Windows PowerShell, Command Prompt, macOS Terminal, Ubuntu Terminal, or the VS Code integrated terminal.

Docker is installed but not running

Open Docker Desktop and wait until it finishes starting. Then rerun docker ps.

Port 8070 is already in use

Another service is using the port expected by the app. Stop the other service or stop the existing GROBID container with docker stop grobid.

Check GROBID fails in the app

Confirm Docker is running, GROBID has finished starting, and http://127.0.0.1:8070/api/isalive responds from the same computer running server.py.

Few or no citation suggestions appear

Suggestion quality depends on PDF quality and reference formatting. Scanned PDFs, incomplete PDFs, or unusual reference sections may produce weak results.
