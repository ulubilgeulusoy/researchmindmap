What You Are Setting Up

Research Mind Map is a local web application. The page opens in your browser, but the app is served by a small Python backend running on your own computer.

You will use Git to download the project, VS Code to open the folder, Python to run the backend, and a virtual environment to keep this app's Python packages separate from other projects.

Install Tools

Install these first:

  • Visual Studio Code: code editor used to open the project folder.
  • Git: command line tool used to clone the repository from GitHub.
  • Python 3: programming language used by the local backend.
  • A modern browser: Chrome, Edge, Firefox, or Safari.

After installing Python, open a new terminal and check that Python is available:

python --version

On some systems the command is:

python3 --version

Check Git the same way:

git --version

Clone the Repository

Cloning means downloading a copy of the GitHub repository to your computer.

Option 1: Clone with VS Code

Use this option if you prefer clicking through the VS Code interface instead of typing Git commands.

  1. Open Visual Studio Code.
  2. Open the Command Palette with Ctrl + Shift + P on Windows/Linux, or Cmd + Shift + P on macOS.
  3. Type Git: Clone and select it.
  4. Paste this repository URL:
https://github.com/ulubilgeulusoy/researchmindmap.git
  1. Choose the folder where you keep software projects.
  2. When VS Code asks whether to open the cloned repository, choose Open.

If VS Code says Git is not installed, install Git first, restart VS Code, and try again.

Option 2: Clone with the Terminal

Use this option if you are comfortable running commands. On Windows, use PowerShell or Command Prompt. PowerShell is recommended because it is the default terminal in VS Code.

First, choose a parent folder where you want to keep software projects. For example, you might create or use one of these folders:

C:\Users\YourName\Documents\Software Applications
C:\Users\YourName\Documents\GitHub
C:\Users\YourName\Desktop\Software Applications

Replace YourName with your Windows username. If the folder path has spaces, put quotes around it when using cd.

PowerShell example:

cd "C:\Users\YourName\Documents\Software Applications"
git clone https://github.com/ulubilgeulusoy/researchmindmap.git
cd researchmindmap

Command Prompt example:

cd /d "C:\Users\YourName\Documents\Software Applications"
git clone https://github.com/ulubilgeulusoy/researchmindmap.git
cd researchmindmap

macOS/Linux example:

cd ~/Documents/software-applications
git clone https://github.com/ulubilgeulusoy/researchmindmap.git
cd researchmindmap

If your parent folder does not exist yet, create it first. On Windows PowerShell, this example creates a folder in Documents:

mkdir "$HOME\Documents\Software Applications"

Then move into it and clone the repository:

git clone https://github.com/ulubilgeulusoy/researchmindmap.git
cd researchmindmap

The first command downloads the repository. The second command moves your terminal into the new project folder.

Open in VS Code

If you cloned with VS Code and chose Open, you can skip this step.

If you cloned with the terminal, open the project in VS Code from inside the researchmindmap folder:

code .

If that command is not available, open VS Code manually, choose File, then Open Folder, and select the researchmindmap folder.

In VS Code, open the integrated terminal from Terminal, then New Terminal.

Create a Virtual Environment

A virtual environment is a project-specific Python workspace. It keeps this app's dependencies isolated from other Python projects.

In the VS Code terminal, run:

python -m venv mindmapenv

Activate it on Windows PowerShell:

mindmapenv\Scripts\Activate.ps1

Activate it on macOS or Linux:

source mindmapenv/bin/activate

When activation works, the terminal prompt usually starts with (mindmapenv).

Install Dependencies

Dependencies are Python packages the backend needs. Install them inside the activated environment:

python -m pip install -r requirements.txt

Run the App

Start the local backend:

python -m uvicorn server:app --host 127.0.0.1 --port 8000

Leave that terminal running. Open this address in your browser:

http://127.0.0.1:8000

The app should open with the included Demo project.

Stop the App

Go back to the terminal running Uvicorn and press Ctrl + C. The browser page will stop working until you start the backend again.

Troubleshooting

python is not recognized

Python is not installed, or it was not added to your system path. Install Python again and choose the option to add it to PATH, or try python3.

PowerShell blocks activation

If Windows blocks Activate.ps1, open PowerShell as your normal user and run:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Then close and reopen the terminal.

Port 8000 is already in use

Another app is using the same port. Run the backend on a different port:

python -m uvicorn server:app --host 127.0.0.1 --port 8001

Then open http://127.0.0.1:8001.

The page looks outdated after a change

Use a hard refresh in the browser. On Windows and Linux, press Ctrl + F5. On macOS, press Cmd + Shift + R.
