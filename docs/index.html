Glossary

Terms Used in This Project

Research Mind Map
The local app in this repository. It helps organize publications, ideas, notes, citations, and writing structure as a visual map.
Node
A map item, such as a publication or idea. Nodes can have notes, tags, keywords, links, and formatting.
Edge / Connection
A line between two nodes. Connections can represent conceptual links, citation links, or other relationships.
Project
A separate workspace with its own map, autosaves, snapshots, copied PDFs, and note images.
Autosave
The app's continuously updated working save stored under the active project folder.
Snapshot
A timestamped manual save point created by the Save button. Use snapshots as recovery points.
VS Code
Visual Studio Code, the editor used in the beginner guide to open the repository and run terminal commands.
Git
The version-control tool used to clone the repository from GitHub and track project files.
Virtual Environment
A project-specific Python environment that keeps this app's dependencies separate from other Python projects.
FastAPI
The Python backend framework used by server.py to serve the app and local API endpoints.
Uvicorn
The local server command used to run the FastAPI backend on an address like http://127.0.0.1:8000.
Cytoscape.js
The JavaScript graph library used to display and interact with the visual mind map.
Jodit
The rich-text editor used in the document workspace for notes, formatting, links, images, and tables.
OpenAlex
An open scholarly metadata service used by the app to discover related papers and citation-direction results.
Zotero
A reference manager used by the app to import publication metadata and access local PDF attachments.
GROBID
A local citation-analysis service that extracts references from PDFs so the app can suggest citation links.
Docker
A container tool used to run GROBID without installing GROBID directly into the Python environment.
Docker Desktop
The Windows and macOS app for running Docker and managing containers such as the reusable grobid container.
PDF Annotation Extraction
The workflow that reads highlights, comments, and notes from local PDFs and appends selected annotations to publication notes.
Tailscale
A private networking tool that can expose the local app to trusted devices without making the backend public.
